# Imágenes de las propiedades de ejemplo

Para usar fotos reales, reemplaza cada archivo por tu foto con **el mismo nombre**
(puede ser .jpg, .jpeg, .png o .webp; si cambias la extensión, borra el .jpg viejo)
y ejecuta:

    php artisan db:seed --class=PropiedadSeeder
